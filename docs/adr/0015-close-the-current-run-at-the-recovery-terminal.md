# ADR 0015: Close the current run at the recovery terminal

Date: 2026-07-23

Status: Accepted

## Context

ADRs 0012–0014 make the desktop journey discoverable, causally ordered, and
cumulative, but the rendered dramatic hierarchy does not end with that causal
order. Operator and Extent provide the strongest transformation. Parent Process
then occupies a large climactic composition even though its job is the narrower
handoff from attached response to retained custody. After all three fixed child
requests are retained, the sequence reports operational completion and returns
to Archive, whose dominant parent receipt reopens the prior condition.

The correction must preserve the sole first unpack, evidence order, transformed
Operator, response reconciliation, fixed Archive record order, Parent and
fragment state meanings, all existing routes and version-2 fields, local-only
privacy, complete erasure, native Back, reduced motion, intentional fragment
404s, and mobile deferral. It must not add an ending route, explanation, badge,
progress model, menu, or finality claim about ORISON as a whole.

## Decision

Treat transformed Operator as the dramatic climax and the existing root
terminal as the ending of the current completed run.

After all of `response-attached`, `orphan-released`,
`fragment-probe-013`, `fragment-probe-027`, and `fragment-probe-058` are
present, `/` renders a retained terminal condition derived entirely from those
flags. The archive remains present; the response source and parent trace are
retained; requested addresses `013`, `027`, and `058` are retained; the
detached-operation queue is empty; displaced addresses `014`, `028`, and `059`
remain unresolved. The command input and quick action are absent because no
detached narrative operation remains. Processing and erasure utilities remain
neutral and unchanged. No completion flag is added.

The all-three fragment receipt returns forward to `/` instead of Archive.
Native Back from the completed terminal returns to the completed fragment
receipt. The completed terminal deliberately exposes no forward link back into
Archive or the late-route sequence: restoring that link would recreate the loop
this bookend closes. A later direct revisit therefore presents the same quiet
endpoint, with only the neutral processing and erasure utilities available.
Reload and a fresh revisit with the same completed v2 trace render the same
terminal condition. Partial traces retain their current root, Archive, and
fragment behavior.

Once response reconciliation completes, both the visible recovered path and
the root quick action lead directly to ordered Archive instead of inserting an
already-completed inode visit. The first unpack path continues to lead to the
inode and remains the sole full recovery operation.

Keep Parent Process inside Archive's left operational column, immediately after
the attached-response evidence and before detached-child continuation. Present
it as a compact custody control and persistent receipt. Completion states that
the orphan did not terminate but that its parent changed; it does not own the
page's dramatic climax. The release action and subsequent fragment continuation
must fit within the initial 1440×700 desktop viewport.

Reserve monumental single-glyph scale for Operator. Recovered-record titles use
a bounded scale while retaining their serif, paper, or route-specific
composition. Mono remains the causal and actionable voice; serif carries one
interpretive claim; narrow sans remains institutional evidence. Existing color
roles are unchanged, including red only for fault, absence, or unresolved work.

Schedule the one-time mechanical apertures only on the safe early Archive return
from Camera or Weather, before Operator has been probed. Recheck eligibility
when the delayed manifestation fires. It must not overlap reconciliation,
Parent, fragments, or another late operation and must not create horizontal
overflow.

Treat Staff insertion as visible evidence rather than visit-count bookkeeping.
An early Staff visit renders a pending source. Letter becomes eligible only
after Weather and Integrity are resolved and Staff was opened after Integrity,
or Staff has been opened more than once. The latter permits prior Staff
exposure to cross the insertion threshold when Integrity is subsequently
resolved. Staff and Archive evaluate the same predicate so they cannot report
opposing insertion states. This uses existing visit order and count state.

## Consequences

- The current rhythm is sole unpack, evidence, Operator/Extent confrontation,
  response reconciliation, Parent custody, cumulative requests, and a quiet
  transformed-terminal bookend.
- Completed v2 traces obtain the bookend without conversion. Legacy migration
  still excludes response, Parent, fragment, and fragments-route state.
- No route, durable flag, schema version, migration, backend, request, external
  asset, dependency, privacy behavior, or infrastructure rule is added.
- Keyboard, pointer, native Back, reload, revisit, reduced motion,
  interruption, fixed 404, and erasure contracts remain required validation.
- This is an ending for the current complete run, not a finite explanation or
  permanent end to ORISON. A future accepted expansion may supersede the
  derived root condition deliberately.
- Behavioral rollback restores the prior fragment-to-Archive link, root
  presentation, Parent scale, and handoff destinations. Existing flags remain
  valid; no state or infrastructure rollback is required.
