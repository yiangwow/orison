# ADR 0016: Make Controlling Source the canonical Operator ingress

Date: 2026-07-24

Status: Accepted; presentation amended by ADR 0017

## Context

Letter already reveals Operator residue, but its canonical continuation enters
the unresolved Operator state without showing the controlling source implied by
that residue. The correction must make that handoff legible without weakening
the existing absent `0`, occupied `1`/`SHE`, or retained root-terminal climaxes.

## Decision

On the first canonical Letter → unresolved Operator transition, render one
transient credible controlling-terminal/process log inside the existing left
search-instrument. The visual log is `aria-hidden`; concise status announces
only start and completion. Spend eligibility immediately through the existing
`operator-probe`, before the visual sequence, and resolve into the existing
unresolved `0`.

Direct entry, reload, interruption, Back/Forward restoration, revisits, and
migrated traces with a prior `operator-probe` skip the transient ingress and
render the ordinary existing Operator state. Normal motion is approximately
2.35 seconds; reduced motion uses an approximately 0.85-second static result.
Existing controls, focus behavior, history, invitation isolation, local erasure,
and the later Extent/occupied-Operator sequence remain unchanged.

No route, durable state, schema, migration, dependency, asset, request, backend,
or privacy behavior is added. The one runtime document remains within a 3,072
byte uncompressed delta and shared assets remain unchanged.

## Consequences

- Letter becomes the first canonical ingress to unresolved Operator while known
  static URLs and all replay paths keep their existing behavior.
- `operator-probe` keeps its existing meaning and is written only at the
  Operator render boundary, before the transient ingress begins. Reload or
  interruption therefore cannot replay a partially observed sequence.
- Complete local erasure removes that probe with the rest of the trace, so a
  new canonical trace may earn the ingress again.
- The Operator `0`, occupied `1`/`SHE`, and retained root ending remain their
  existing dramatic conditions.
- Regression coverage must retain first ingress, direct and replay paths,
  interruption, reload, Back/Forward, migration, reduced motion, accessibility
  status, focus, invitation isolation, erasure, and asset/byte constraints.
- Rollback is a revert of the document, test, and documentation changes; no
  migration or state conversion is required.
